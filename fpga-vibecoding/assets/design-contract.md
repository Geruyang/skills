# 设计契约

按项目填写相关项；未知写“待证据”，不填臆测的默认值。简单模块只保留必要字段。

| 项目 | 内容与证据 |
|---|---|
| 功能与验收 | 输入、预期输出、可自动判断的通过标准 |
| 板型与修订 | 用户声明、实物核验、资料版本；关联板卡记录 |
| 开发路径 | 原厂 EdgeBoard 应用 / 自研 PL / 有证据的扩展集成 |
| 工具链与平台 | Vivado/HLS/Vitis/BSP/内核/SDK/固件/模型工具版本 |
| 数值语义 | shape、layout、dtype、字节序、定点/量化、舍入/饱和 |
| 时钟与复位 | 各 domain 频率/来源、复位极性与释放、CDC 方法 |
| 控制接口 | AXI-Lite/寄存器地址、访问语义、启动/完成/错误/中断 |
| 数据接口 | AXI-MM/Stream、位宽、burst、对齐、TLAST/TKEEP/TUSER |
| 存储与所有权 | 地址空间、buffer 分配、CPU/DMA 所有权、cache/一致性 |
| 外部接口 | pinout/VCCO/时序来源、传感器/外设准确型号 |
| 性能预算 | 代表输入、吞吐、端到端延迟、资源、DDR 带宽、功耗 |
| 出错行为 | 超时、复位、坏包、溢出、驱动失败与恢复 |
| 验证计划 | 软件参考、自检仿真、实现报告、板上闭环及日志路径 |
| 交付与回退 | 重建命令、产物/哈希、部署目标、基线镜像/恢复方式 |

实现变更时先更新受影响的接口字段和测试，不要求无关部分反复改写。
