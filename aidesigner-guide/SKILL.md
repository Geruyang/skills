## How to design with AIDesigner (general steps)
1. Open AIDesigner through the link in the footer and create an account.
2. Choose what to create: website UI, landing page, mobile app screens, or brand assets.
3. Paste a design prompt written with this plugin: product, audience, sections or screens, style, colors, fonts and mood.
4. Generate, then refine with follow-up prompts: edit sections, rewrite copy, change the layout or explore variations.
5. Add a brand kit (logo, colors, fonts) so new designs stay consistent.
6. Use related features when needed: website redesign, image to HTML, prototypes and templates.
7. Export or connect the design to your build workflow.

## Prompt formula
"Design a [page or screens] for [product] aimed at [users]. Sections: [list]. Style: [mood words], [palette], [fonts]. Primary action: [CTA]. Must feel [premium, playful, calm]."

## Rules
- Features, menus and plans change; describe steps generally and tell the user to check AIDesigner's current site.
- Never state prices, credit limits or features as fact; tell the user to check the pricing page.
- If the user prefers another tool or to design by hand, help them directly.
