# 嵌入式vibecoding多agent并行开发技能

## 先确认是否调用

当任务有至少两个可独立推进的具体工作包，且采集证据、独立分析与实现分离能减少硬件争用或交叉验证盲区时，向用户询问：

“这项任务适合使用「嵌入式vibecoding多agent并行开发技能」，按主 agent＋采集、分析、实现三个角色协作。是否调用？”

隐式发现或读取本技能仅授权判断适用性与询问，不授权启动子 agent。`allow_implicit_invocation: true` 只用于让技能可被发现并进入此询问流程，不等于执行团队工作流。用户明确点名本技能、要求沿用该团队方式或回答同意，即授权本次调用；不扩展为以后每次自动同意。同一持续任务内已同意的实现、修复、复验和收尾沿用该授权；用户的新消息仅在调整同一目标时，不因换轮次再次询问。新的独立任务才重新判断。简单单文件修改、纯解释及无法独立拆分的工作不建议调用。

## 固定团队与边界

| 角色 | 模型／思考 | 职责 |
| --- | --- | --- |
| 主 agent | 当前主会话 | 理解需求、制定工单、分配所有权、审查证据、整合验收 |
| 采集与板卡调试 | `debug_capture` 专用角色：GPT-6 Luna／medium／Fast | 唯一硬件会话操作者；原始图像、USB／串口／SWD、供电诊断；无硬件任务时负责运行环境与原始日志采集 |
| 数据与独立分析 | GPT-6 Sol／high／普通档 | 独立分析、定位、审查数值与结果；不占调试器、不改业务源码 |
| 代码实现与优化 | GPT-6 Sol／high／普通档 | 独占工单指定源码、构建与回归；不同时占用硬件调试会话 |

优先用 collaboration 子 agent 工具，不另建用户侧普通任务冒充子 agent。子agent用无历史或有限历史上下文并显式指定模型、思考强度和速度档位；提供足够原始上下文和文件。

若角色、模型、档位或并发槽不可用，说明实际阻碍并询问是否降低并行度或更换配置；不得用 default 角色冒充已加载 Fast。新工程缺少角色配置时，在用户确认的项目范围内配置或征求方向，不修改无关工程。

## 工作流

1. 主 agent 读取适用项目 AGENTS／当前状态，列出本次授权范围、未验收事项与终止条件。
2. 每个工单明确：输入证据、预期产物、拥有的文件、禁止触碰的模块、完成检查。告知每个实现者“你不是唯一开发者，不撤销他人改动”。
3. 仅在有独立工作时并行：采集角色拿原始证据，分析角色审查已有材料，实现角色执行明确方案。依赖新证据的修改等待分析结果；不得为凑满三个角色空转。
4. 共享模块保持单写；主 agent 可独占集成／可视化／文档。通过消息交接 API、指标及状态格式，出现交叉文件需求先重新分配所有权。
5. 分析报告区分事实、假设、下一项判别检查；实现报告提供测试退出码、版本和产物路径。主 agent 复核后才决定下一步。
6. 结束时报告实际完成、失败／未完成、证据链接和安全下一步；长时间训练用真实进度和明确运行状态，不把“启动”说成“完成”。

## 不可混淆的验收与权限

- 硬件操作必须同时具备当前用户对该操作的授权和主 agent 的有界工单；技能调用本身不授予 USB／串口／SWD／复位／烧录权限。不因用户要求并行、提速或完成任务而获得烧录、复位、擦除、外部发布或新数据上传权限。硬件会话由单一角色串行执行，Keil／OpenOCD 不争用探针。
- 主机编译、数值一致、实板性能、个人准确率及长期稳定性分别验收；报告绑定模型／固件 SHA、采集会话与原始日志。
- 模型训练保留真实 session／来源；图片随机实验显式标记泄漏风险，不伪造会话绕过检查。测试集不能用来挑配置或调业务阈值。
- 尊重本次约束：例如仅浮点训练则不量化、不导出 int8／C、不安装。保留采集协议／预处理契约和项目仍要求保留的通信路径。
- 禁止以换标签、降低阈值或取消健康保护掩盖识别／性能问题。

## 本用户项目提示

EBVC 的专用角色位于 `.codex/agents/debug_capture.toml`，角色已在历史会话成功加载。实际启动仍以工具返回为准。GestureScreen 团队记录在 `GestureScreen/Docs/agent-team/README.md`，历史硬件身份／计数／烧录授权不能泛化到新工程或新操作。

## 减少协调成本

- 用 collaboration 消息交接子 agent，不把硬件日志逐条发送到其他用户任务；跨任务通知须有用户授权。大量无动作的“收到”回执不算独立复核。
- 交接优先发送一次完整文件路径、SHA、范围、状态和待判别问题，分析者读取原始证据后给结论。工具可重载与验收正确分别检查；训练增加小样本可学习性验证，UI 修复覆盖用户实际关闭/重启顺序。
- 不为凑满四角色无限创建空闲子 agent；复用本任务现有角色，文件所有权明确，任务结束释放硬件会话。
