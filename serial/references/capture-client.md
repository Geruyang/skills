# 串口图像采集服务与便携客户端

## 单一端口所有者

已运行的采集服务是串口唯一所有者；监控通过它的 HTTP/lease 接口获取证据。不要另开 COM 口读取来检查连接。多客户端可观察，录制控制须有单一 owner，过期 lease/迟到请求不能重获控制。复位/烧录后帧号可能回退，结束旧诊断 session 后再开新 session，不能关闭去重保护掩盖回退。

## 录制数据契约

预览、临时录制、保存历史和训练审阅分别建模。正常关闭/新建会话如何清理，以用户要求为准；异常断连可冻结临时内容供恢复，已保存历史不受临时清理影响。预览在途请求不应阻塞保存、导出和标注。新目录在隐藏暂存区构建，完整成功后原子发布，避免写盘失败留下不可重启状态。

“全量录制”模式保留所有协议完整且提交成功的帧，包括重复、黑白画面；CRC 坏帧仍按协议拒收。录制意图标签、模型提示、训练合格标签不能混同；外部清洗模式导出显式标记 unreviewed、training_ready=false。这些是可配置产品要求，不应强加给需要自动筛选的其他产品。

网页请求使用有界超时、取消和代际编号；暂停后迟到的预览/画廊响应不得覆盖新状态。下载按发起页面关联，双窗口共享同一兼容后台但不共享不相关数据根。

## Windows 单文件 EXE

用户选择便携模式时，默认数据根取 sys.executable 父目录/captures；相对 CLI 路径同样相对于 EXE。媒体清单使用相对路径。不用 cwd、_MEIPASS 或固定开发路径当用户资料根；新电脑仅复制 EXE，首次启动创建空目录，旧资料迁移是可选动作。

复用服务前验证协议 capability、模型哈希和数据根；默认端口冲突可选空闲端口，port hint 不保存过期绝对目录或认证令牌。不可写位置给明确错误。

PyInstaller onefile 父窗口退出警告可由后台子进程占用父 _MEI 引起。核查子进程 cwd、继承 PATH/Qt 路径及 Windows DLL 搜索目录，使用独立后台解包环境；临时改变 DLL 搜索目录后恢复父进程设置。Qt 页面/profile 按生命周期销毁。不用关闭 Chromium sandbox、隐藏错误或强杀所有同名窗口代替修复。

验证从“目录里只有 EXE”开始，覆盖中文/空格路径、双窗、默认端口被占、完整录制/保存/导出、移动资料目录、窗口先关而后台仍活着及后台 idle 自然退出。仅从源码或等待后台先退再关 GUI，不能覆盖 onefile 正常退出问题；Win11 通过不能称 Win10 已实机通过。
