# 对话提炼：用户的研究要求

来源：2026年9月本任务中的A股研究对话。本文件是可复用的要求摘要，非完整逐字聊天记录，也不保存临时投资结论。

## 用户明确表达的需求

- 最初要求结合A股近期走势、国内外重大事件、外围市场、全球气候和国际局势，分析粮食、猪肉、红利低波，并形成PDF。
- 后续要求预测一周、两周、两个月和半年，给出具体涨跌幅，并推荐较有上涨机会的新板块。
- 用户提醒：“为什么这么悲观呢，不考虑预期交易吗”。这要求检查是否忽略领先变量，不代表必须提高所有涨幅或总是给看涨答案。
- 用户要求“还需要考虑过往历史相似情况”，以及“再将资金流入流出也纳入考虑”。
- 用户强调：“分析股市未来的走向需要预测未来的数据，比如未来粮食的产量减少，存栏能繁母猪数量等等，不能仅凭当前数据，股市会交易预期”。
- 用户要求将这套对话经验保存成skill，以后参考。
- 用户随后要求：调研A股必须调用本技能，名称改为“A股预测补充skill”。这项持续偏好通过个人全局指令和技能触发说明共同保存；有效技术标识仍为 `ashare-forward-expectations`。

## 对研究行为的实际改变

旧式流程容易停在：当前资料 → 风险罗列 → 资金是否流入 → 保留旧区间。

本用户希望看到：领先数据 → 未来供需/盈利预测 → 与原有预期比较 → 判断已计价程度 → 催化时间与价格传导 → 当前可执行的研究结论及失效条件。

把“等待数据确认”当唯一办法会错过预期交易。应该在数据尚未兑现时给出有依据的预测，说明哪里是推断；随后利用实际披露与资金/价格变化更新信心。

股价可能提前上涨，也可能在数据公布后继续涨或反向下跌，取决于超预期程度、仓位与估值。不要将用户关于提前交易的提醒，扩大成“公开数据毫无价值”或“数据公布必见顶”的规则。

## 持续保留的边界

- 不强制长期推荐同一个板块，也不把本轮创新药、猪肉或红利排序固定下来。
- 不把某一次ETF样本金额保存为以后可继续使用的事实。
- 不推断用户的持仓、成本、资产规模、风险承受力或杠杆偏好。
- 创建技能不等于获得交易、定时监控、外部发布或替用户发送信息的授权。
- 本用户要求明确预测；应给有条件的观点和量级，同时如实说明预测并非保证。
