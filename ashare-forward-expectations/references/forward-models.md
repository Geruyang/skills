# 前瞻模型与口径

这些是可调整的研究工具，不是已训练的预测器。参数需要本次数据与经济理由，禁止把示例当默认结论。

## 粮食产量与库存

分作物和地区计算：产量 = 收获面积 × 单产。全球变动 = 各产区变动加总，不将一个产区减产率直接套到全球或中国。

期末库存 = 期初库存 + 产量 + 进口 - 国内消费 - 出口 ± 统计调整。
库消比 = 期末库存 / 对应口径的年度消费。

国内供需和全球供需分开。全球进口与出口在加总中大体抵销，但各国作物年度和统计差会留下差异，应沿用来源定义。库存下降可能来自需求增加，产量增加也可能伴随库存下降。

对未来官方预测修订建模时，写清目标是“届时对2026/27作物年度的产量估计”，并非截至预测日期已经收获的累计产量。若保持消费不变来展示产量冲击，明确这是单因素敏感性；现实需求和贸易会响应。

将天气预测拆成：气候状态概率 → 产区降水/温度 → 生育阶段影响 → 单产 → 产量/库存 → 国内价格传导 → 上市公司盈利。每一层都可能被灌溉、播种调整、政策库存和进口替代削弱。

## 母猪、仔猪与生猪供给

简化月度存栏模型：S(t+n) = S(t) × Π[1+g(m)]。

若月变化率固定，可写为S(t) × (1+g)^n；这个g是情景假设，不是已经知道的未来降幅。最近官方数据滞后于研究日时，先区分未公布月份的估计与真正未来月份的预测。

年度供给近似：有效母猪 × 每母猪年提供商品猪数 × 平均出栏体重。用于预测变化时，保持效率指标定义一致；PSY、MSY、出生仔猪数不是同一个指标。使用MSY后不要再乘一次已被MSY包含的成活率。

时滞模型可用不同月龄队列或分布滞后，不应把10个月当所有场景中精确不变的常数。仔猪数据比当期母猪更贴近未来5-6个月的出栏。二次育肥、压栏、出栏体重与疫病可能改变短期数量和重量。

母猪减少5%、单位母猪产出增加4%时，供给近似变动为0.95×1.04-1=-1.2%，并非减少5%。这是算术示例，不能直接当某个年份预测。

养殖利润可从(售价-单位成本)×出栏重量×数量估计。亏损转盈利阶段，利润增速和PE可能失真，宜用正常化利润、资产或现金流估值，并说明仍存在周期估计误差。

## 从未来盈利到指数价格

在盈利为正且口径一致的简化情景中：

价格变化 = (1 + 对同一未来盈利年度的修订率) × (1 + 该盈利口径的估值倍数变化率) - 1。

例如两个预测日都讨论2027全年盈利，不能一端用2026滚动盈利、另一端用2027预测盈利，再把增长全部称为预期差。若当前市场真实盈利预期不可取得，将基数100标为研究者基线，避免暗示观测到了共识。

指数层面应考虑样本权重、盈利亏损混合、再平衡及摊薄。用代表公司或正常化盈利代理作情景时，说明并非严格的指数目标价模型。创新药可以分持续销售、现金、概率加权管线和CXO订单；不要将单家公司BD首付款乘到全指数。

估值扩张假设可由利率、风险溢价、兑现可信度和资金承接解释，但不能将同一利好同时在盈利、估值和另加“资金贡献”中重复计算。保留估值下降或不变的情景。

## 价格、资金与历史计算

收益率 = 目标日收盘 / 基点收盘 - 1。目标日休市按约定取前一交易日；遇市场节假日，应核对交易所日历，不能把两个自然周默认成10个交易日。

ETF净申赎金额常用Σ(每日份额变化×当日净值)估算。需先处理拆分、合并及份额折算；行情商采用均价会与净值方法不同。未经完整序列复算，不把媒体金额包装成自己计算的官方现金流。

统计回测需要预先定义信息集、锚点、持有期和比较基准。若只展示历史案例，明确样本选择理由和不相似处。只取得最新修订后的宏观数据时，不能假装它们就是事件当时可获得的数值。
