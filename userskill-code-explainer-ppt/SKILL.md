## 跨客户端运行约定

本导出版本供智谱 ZCode、Claude Code 及支持 SKILL.md 的 Agent 使用。下文中的“当前 Agent/客户端”指实际执行环境；关于 Codex、OpenAI、ChatGPT 的产品说明仍指对应产品。
技能根目录以本 SKILL.md 所在目录为准，示例中的 E:/AIProject/skills 是本次导出库，可按安装位置调整。使用当前客户端真实提供的文件、终端、检索、任务与子 Agent 能力；旧工具名不是可用性证据。优先遵守当前客户端的权限规则和用户授权。
以下迁移约定优先于保留正文中涉及运行环境、专有工具和呈现语法的旧要求；领域流程、验证要求、硬件/数据接口和用户偏好继续适用。完整限制见 [PORTABILITY.md](PORTABILITY.md)。



# UserSkill-工程代码讲解PPT

把当前工程中真实存在的代码、修改与验证结果，整理成读者能跟随源码理解的中文演示。用户要求配音时，再扩展到语音与同步标记。本技能中的“语音”或“配音”是泛称，可来自用户录音、导入音频、本地或系统 TTS、以及任意声音插件；不默认指代苏晴或任何单一音色。此技能由用户要求从实际任务经验整理，技术标识采用小写以符合技能发现格式，界面名称保留 `UserSkill` 前缀。

## 进入任务

1. 简短说明使用本技能。读取工程自己的 `AGENTS.md` 与相关文档，定位当前源码和已有 PPT。制作 PPT 本身不构成修改固件或应用代码的授权。
2. 读取 [代码与演示工作流](references/code-workflow.md)。若用户指向另一段聊天，使用可用的任务读取工具取得其实际内容，再与当前文件核对。
3. 从已有上下文判断读者、修改范围、页数和播放软件。需要音频或对象动画时，尽早确认 WPS / PowerPoint 及实际使用环境，同时继续整理源码。该用户在 2026-09-14 明确使用 WPS；后续未指定软件时优先考虑 WPS 兼容，但不要把历史环境当作永不改变的事实。
4. 有配音、随讲解标记或播放故障时，读取 [配音与同步](references/narration-sync.md)。纯静态 PPT 无须引入 TTS、视频或额外放映步骤。
5. 使用当前可用的演示制作技能与依赖入口进行版式、导出和最终检查；本技能补充工程讲解与经验回写，不复制其他技能的版本化安装路径。优先使用用户提供或明确指定的录音、TTS、音色与声音插件；只有用户明确选择苏晴时才读取并调用苏晴语音技能。未指定时使用当前可用且适合任务的方案，不把任何单一音色写成技能依赖。

## 交付前必须完成

- 讲解中的代码、参数、改动归属与当前工程证据一致；旧片段明确标明快照，未实现和未验证部分如实说明。
- 正文、代码与表格按需求保持可编辑。原始 PPT 保留，新输出使用能区分版本的文件名。
- 检查最终文件而非仅中间截图；配音与标记核对最终嵌入的媒体和实际播放结构。
- 区分内容核对、静态渲染、媒体时间核对与目标软件实播。视频同步通过不能证明 PPT 在 WPS 中同步，文件结构通过不能证明实际放映正常。
- 执行下面的自动经验回写，再交付文件。说明会影响使用的限制；不把内部验证报告当作用户要求的讲解页。

## 每次任务自动回写经验

用户已经要求每次工程代码 PPT 任务自动更新本技能，不需要逐次重新询问是否记录经验。这是任务完成时执行的步骤，不是后台定时任务，也不是声称系统在无人运行时会自我学习。

每次生成、重做或修复工程代码 PPT 后，按 [自动经验回写协议](references/learning-loop.md) 执行：

1. 复盘用户纠正、实际失败、经过验证的改进及本次尚未验证的内容。
2. 有新知识时，更新最相关的参考文档或必要脚本；替换过时结论，不只追加历史。只有改变通用决策时才修改入口文件。
3. 使用 `scripts/update_experience.py` 将本次复盘记录及去重后的经验写入 `references/experience.json`。没有新经验也登记“已复盘，无新增”，不为更新而虚构规则。
4. 验证修改后的技能结构；有脚本变化时执行相关功能检查。全局规范、用户显式约束与执行权限继续有效。

回写前重新读取目标文件，避免覆盖其他任务的更新。若个人目录写入被执行权限阻止，保留项目内待回写文件，清楚报告待完成部分，不能把项目副本当成已更新的个人技能。

项目收尾、清理旧 PPT 或归档讲解资料时，使用 [代码与演示工作流](references/code-workflow.md) 的“项目收尾与历史讲解”规则，保留各主题最终版本及实际外链依赖。
